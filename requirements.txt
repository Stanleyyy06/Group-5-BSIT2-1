## 🚀 Three Ways to Use PostgreSQL

### Option 1: Local Development with Docker (Fastest)

```bash
# Start PostgreSQL + Flask in one command
docker-compose up -d

# App automatically connects to PostgreSQL
# Database tables created on startup ✅
```

### Option 2: Railway Production (Easiest for deployment)

1. Create Railway project with PostgreSQL
2. Set environment variables (see below)
3. Push to GitHub → Railway auto-deploys

**Required Environment Variables:**
```env
DATABASE_URL=postgresql://... (auto-set by Railway)
SECRET_KEY=<generate using script below>
ADMIN_USERNAME=admin
ADMIN_PASSWORD=<strong-password>
FLASK_ENV=production
SESSION_COOKIE_SECURE=True
```

### Option 3: Manual PostgreSQL Installation

```bash
# Install PostgreSQL locally
# Create database and user:

psql -U postgres
CREATE DATABASE netad_db;
CREATE USER netad_user WITH PASSWORD 'netad_password';
GRANT ALL PRIVILEGES ON DATABASE netad_db TO netad_user;

# Load schema:
psql -U netad_user -d netad_db -f postgres_schema.sql

# Update .env:
DATABASE_URL=postgresql://netad_user:netad_password@localhost:5432/netad_db

# Run app:
python app.py
```

## 🔑 Generate Secure Secret Key

**On Linux/Mac:**
```bash
bash generate_secret_key.sh
```

**On Windows:**
```cmd
generate_secret_key.bat
```

**Or manually:**
```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

Copy the output to your `SECRET_KEY` environment variable.
